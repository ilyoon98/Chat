# 똥겜사랑단 놀이터

우리끼리 하는 게임 기록을 모아 두는 웹페이지예요. 게임마다 탭이 하나씩 있고, 지금은 **롤 내전** 탭이 있어요.
롤 내전 탭에서는 친구들끼리 팀을 섞고, 승패를 기록하고, 승률·MMR·천적·듀오를 봐요.
Vercel에 올리면 링크만 있으면 **로그인 없이 누구나** 같은 기록을 봐요.

```
index.html        화면 전체 (팀 섞기, 전적, 분석, 기록)
api/data.js       기록 저장 API (Upstash Redis 사용)
dev-server.mjs    내 컴퓨터에서 테스트용 (.dev-data.json 파일에 저장, 배포엔 안 씀)
```

## 배포하기 (처음 한 번, 10분 정도)

### 1. GitHub에 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `lol-naejeon`). Private이어도 괜찮아요.
2. 이 폴더에서:
   ```bash
   git init
   git add .
   git commit -m "롤 내전 기록실"
   git branch -M main
   git remote add origin https://github.com/<내아이디>/lol-naejeon.git
   git push -u origin main
   ```

### 2. Vercel에 프로젝트 만들기
1. https://vercel.com 에 GitHub 계정으로 로그인해요.
2. **Add New → Project** → 방금 만든 저장소를 **Import** 해요.
3. Framework Preset은 **Other** 그대로 두고 **Deploy**를 눌러요.

### 3. 저장소(DB) 연결하기 — 이걸 해야 기록이 저장돼요
1. Vercel 프로젝트 화면 → **Storage** 탭 → **Create Database**.
2. Marketplace에서 **Upstash for Redis**를 고르고, 무료 플랜으로 만들어요.
3. 만든 DB를 이 프로젝트에 **Connect** 해요. 연결 주소와 키가 환경변수로 자동으로 들어가요.
4. **Deployments** 탭에서 가장 최근 배포의 `⋯` → **Redeploy** 를 눌러요.

이제 `https://<프로젝트이름>.vercel.app` 링크를 단톡방에 올리면 끝이에요.
화면 오른쪽 위에 **"모두와 공유 중"** 이 보이면 정상이에요.

### 4. (선택) 기록 비밀번호 걸기
아무나 기록을 지우거나 바꾸는 게 싫다면:
1. 프로젝트 **Settings → Environment Variables** 에서
   이름 `RECORD_PIN`, 값 `원하는 비밀번호` 를 추가해요.
2. 다시 **Redeploy** 해요.

그러면 보기는 누구나 되고, 명단 수정·승패 기록·삭제할 때만 비밀번호를 물어봐요.
한 번 입력하면 그 기기에선 다시 안 물어봐요.

### 5. (선택) 솔랭 티어 불러오기 — Riot API 키 넣기
1. https://developer.riotgames.com 에 롤 계정으로 로그인해서 API 키(`RGAPI-…`)를 받아요.
2. Vercel 프로젝트 **Settings → Environment Variables** 에서
   이름 `RIOT_API_KEY`, 값 `RGAPI-…` 를 추가하고 다시 **Redeploy** 해요.
3. 사이트에서 **명단 편집 → 이름 누르기 → Riot ID(이름#태그) 넣기 → 솔랭 티어 불러오기**.

- 키는 서버(`api/data.js`)에서만 써요. 화면 코드나 git에는 절대 넣지 마세요.
- **개발 키(Development Key)는 24시간마다 만료돼요.** 만료되면 "키가 만료됐거나 틀렸어요"가 떠요. 새로 받아서 환경변수를 바꾸고 Redeploy 하면 돼요.
  계속 쓸 거면 같은 사이트에서 **Personal API Key**를 신청하세요(친구들끼리 쓰는 작은 사이트용, 만료 없음, 승인 필요).
  키를 바꿔도 이미 연결한 Riot ID는 그대로 써요(서버가 알아서 다시 찾아요).
- 솔랭 티어와 같이 **주 라인·모스트**(최근 솔랭·자랭·일반 20판, 칼바람·다시하기 빼고)와 **숙련도**(챔피언 숙련도 상위 3개)도 불러와요.
- 6시간이 지나면 누가 사이트를 열 때 자동으로 새로 불러와요. 명단 편집 중에 **롤 정보 새로고침**을 누르면 바로 불러와요(10분에 한 번까지).
- 키는 2분에 100번까지만 부를 수 있어서, 처음 한 사람당 20판을 불러올 땐 서너 명씩 나눠서 2분 간격으로 이어서 불러와요. 한 번 불러온 판은 저장해 두고 다음엔 새 판만 불러요.

### 6. (선택) 실시간 신호 — Ably 키 넣기
안 넣어도 돌아가요(화면이 5초마다 물어봐요). 넣으면 방장이 뭔가 바꿀 때만 서버가 신호를 쏘고, 그때만 새로 받아 가서 거의 바로 보이고 Upstash·Vercel 사용량도 크게 줄어요.
1. https://ably.com 에 가입해요(무료, 카드 필요 없음). 앱을 하나 만들어요.
2. 앱의 **API Keys** 에서 키(`앱ID.키ID:비밀값`)를 복사해요. Root 키를 써도 돼요.
3. Vercel **Settings → Environments → Production → Add Environment Variable** 에서 이름 `ABLY_API_KEY`, 값 복사한 키 전체를 넣고 다시 배포해요.

- 키는 서버에서만 써요. 화면에는 그 기기 id로 "듣기·보고 있어요 표시"만 되는 1시간짜리 토큰을 줘요.
- 무료 한도는 한 달 메시지 600만 건, 동시 접속 200명이에요. 우리 규모로는 한참 남아요.
- 채널 이름 앞에 배포 환경이 붙어서(`ddong-production`, 내 컴퓨터는 `ddong-local`) 시험한 신호가 실제 사이트로 가지 않아요.

## 내 컴퓨터에서 미리 보기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 열려요. 이때 기록은 이 폴더의 `.dev-data.json` 파일에 저장돼서 서버를 껐다 켜도 남아요. (배포한 사이트와는 따로예요. git에는 안 올라가요.)
솔랭 티어까지 시험하려면 이 폴더에 `.env` 파일을 만들고 `RIOT_API_KEY=RGAPI-…` 한 줄을 넣어요. 실시간 신호는 `ABLY_API_KEY=…` 줄을 넣으면 돼요. `npm run dev`가 읽어 가요. (`.env`도 git에는 안 올라가요.)

## 기능

- **내전 라인 배정**: 팀이 정해지면 같은 라인 추천 엔진으로 팀마다 탑~서폿을 정해요(팀 섞기 옆 버튼으로 끄고 켜기, 이 기기 설정). 방장은 라인 칸을 눌러 바꾸고(그 라인이던 팀원과 서로 바꿈), 기록한 판의 라인은 선수 카드 "내전 라인"과 다음 추천에 쓰여요.
- **롤 5인 큐** (게임 탭): 친구 다섯이 같이 랭크·일반을 돌릴 때 라인을 추천해요. 명단에서 5명을 고르면 각자 최근 판(사람당 최대 100판)의 라인별 판 수·승률·그 라인 챔피언을 보고, 5명을 5개 라인에 놓는 120가지 경우를 모두 계산해서 1~3순위를 보여줘요. 고른 5명은 그 기기에만 기억돼요.
  - 롤 정보는 새로고침할 때마다 새 판을 받고 예전 판을 20판씩 거슬러 올라가며 서버(Upstash)에 쌓아요. 한 번 받은 판은 다시 안 불러요.
  - 사이트가 열려 있으면 2분 반마다 이어서 모으고, 아무도 안 열어도 Vercel Cron(`vercel.json`)이 매일 새벽 4시에 한 번 모아요. `CRON_SECRET` 환경변수를 넣으면 Vercel이 부를 때만 돌아요.

- **방·방장**: 처음 들어오면 닉네임을 정해요. **새 방**을 만든 사람이 방장이고, 그 방의 오늘 할 사람·팀 섞기·승패는 방장만 바꿀 수 있어요. 나머지는 구경하면서 화면을 실시간으로 봐요.
  - 방마다 오늘 할 사람과 팀 배치가 따로라서 두 판을 동시에 해도 섞이지 않아요. 선수 명단·전적·티어는 모든 방이 같이 써요.
  - 방 위에 "방장: 일윤 · 구경 중 3명(기종, 현일, 호림)"처럼 지금 보고 있는 사람이 나와요(Ably를 쓰면 들어오고 나가는 즉시, 아니면 15초마다 확인).
  - 방장은 구경 중인 사람에게 **방장 넘기기**를 할 수 있어요. 방장이 10분 동안 안 보이면 자리가 비고, 그때 누구나 **방장 하기**를 할 수 있어요.
  - **방 링크 복사**로 카톡에 보내면 바로 그 방으로 들어와요. 12시간 동안 조용한 방은 자동으로 정리돼요.
  - 명단 추가·편집과 기록 삭제는 어느 방이든 방장인 사람만 할 수 있어요.
- **내전**: 명단에서 오늘 할 사람 고르기 → 팀 섞기(완전 랜덤 / 실력 밸런스 / 팀장 뽑기) → 이긴 팀 누르기. 1팀은 블루, 2팀은 레드예요.
  - **팀장 뽑기**: 팀장 정하는 방법(MMR 1·2위 / MMR 꼴찌 둘 / 랜덤)을 고르고, 다른 사람이 하고 싶으면 칸을 눌러 바꿔요. 동전 던지기(또는 직접)로 먼저 뽑을 팀을 정하면, 차례인 팀장이 원하는 만큼 뽑고 **넘기기**를 눌러요. 팀이 다 차면 알아서 넘어가고, 한 명 남으면 자동. 뽑힌 사람은 남은 사람 칸에서 팀 칸으로 날아가요. 뽑는 동안 위에 팀장 둘과 먼저 뽑은 팀이 계속 보여요. 되돌리기 가능. 뽑는 과정은 진행하는 기기에서만 보이고, 끝난 팀 배치가 모두에게 공유돼요.
  - 이름 옆 **화살표(→ / ←)**를 누르면 상대 팀으로 가요. 이름을 끌어서 다른 사람 위에 놓으면 둘이 자리를 바꾸고, 상대 팀 빈 곳에 놓으면 그 팀으로 옮겨져요(폰은 꾹 눌렀다 끌기).
  - **카톡용 복사**로 팀 구성을 단톡방에 바로 붙여넣을 수 있어요.
  - 잘못 눌렀으면 **되돌리기**. 두 사람이 같은 판을 동시에 눌러도 한 번만 남고, 다른 사람 화면도 같이 '기록됨'으로 바뀌어요.
  - 끝나면 **같은 팀으로 한 판 더**(같은 팀·같은 결과여도 새 판으로 기록) 또는 **새로 섞기**.
- **명단 편집**: 이름 바꾸기, 명단에서 빼기, Riot ID 연결(솔랭 티어 불러오기)
  - 오타로 갈라진 전적은 이미 있는 이름으로 바꾸면 하나로 합쳐져요. 같은 판에서 같이 뛴 적이 있거나 지금 팀 배치에 둘 다 있는 두 사람은 다른 사람이라서 합칠 수 없어요.
- **이 방 기록**: 내전 탭 맨 아래에 지금 들어가 있는 방에서 한 판들만 따로 센 승-패·승률·흐름이 나와요. 팀 목록과 선수 카드에도 "이 방 n승 n패"가 붙어요. 전적·분석·기록 탭은 모든 방을 합친 전체 기준이에요(기간은 전체 / 30일 / 7일 / 24시간). 방 기록은 이 기능을 넣은 뒤에 한 판부터 세요.
- **티어**: 이름 앞에 롤 티어 엠블럼이 붙어요. 전체 기간 MMR 순위가 우리 중 상위 몇 %인지를 실제 솔로랭크 분포(챌린저 0.0092% … 아이언)에 맞춘 거예요. 1판 이상 한 사람만.
- **솔랭 티어**: Riot ID를 연결한 사람은 실제 솔로랭크 티어가 전적 표의 "솔랭" 칸과 팀장 뽑기 목록에 글자로 붙어요(엠블럼은 내전 티어 그대로). 배포하기 5단계가 필요해요.
- **주 라인·모스트·숙련도**: 전적 표에 "주 라인"(미드 60% · 정글 25%), "모스트"(최근 많이 한 챔피언 3개), "숙련도" 칸이 생겨요. 팀 칸과 팀장 뽑기에도 주 라인이 붙고, 남은 사람 칸에 모스트 아이콘이 나와요. 아이콘에 마우스를 올리면 판수·승률·숙련도 점수가 나와요. 챔피언 이름·아이콘은 라이엇 공식 Data Dragon에서 받아요.
- **전적**: 판수, 승-패, 승률, MMR, 최근 5판, 연승·연패. 기간(전체 / 30일 / 7일 / 24시간)을 골라 볼 수 있어요.
- **분석**: 승률 1위, 최강·최악 듀오, 천적·먹잇감, 상대 전적표.
- **기록**: 경기 목록과 삭제. **백업 받기**로 전체 기록을 JSON 파일로 저장해 둘 수 있어요.

## 알아두면 좋은 것
- 명단, 오늘 할 사람, 팀 배치, 경기 기록은 모두 서버에 저장돼서 방장이 바꾸면 그 방을 보는 모든 사람 화면에 같이 보여요.
- 방장은 기기마다 만든 id로 구분해요(로그인 없음). 폰을 바꾸거나 브라우저 데이터를 지우면 다른 사람으로 보여서, 다른 방장에게 넘겨받거나 10분 뒤 "방장 하기"를 눌러야 해요.
- Ably를 쓰면 화면은 '바뀜' 신호가 올 때와 2분에 한 번(놓친 게 있을까 봐)만 새 기록을 확인해요. 방장은 방장 자리를 지키려고 2분마다 신호를 보내요.
  Ably 연결이 안 되면 예전처럼 5초마다 확인하고, 화면을 5분 넘게 안 만지면 30초, 30분 넘으면 5분 간격으로 늦춰요. 바뀐 게 없으면 서버가 Redis를 1번만 조회해서, Upstash 무료 한도를 거의 안 써요.
- 선수는 이름으로 구분해요. 같은 사람은 항상 같은 이름으로 넣어야 전적이 이어져요. 틀렸으면 명단 편집으로 고치면 돼요.
- 경기 기록은 최대 5000판까지 저장해요.
- 화면 오른쪽 위 표시가 **"DB 연결 필요"**면 배포하기 3단계(Upstash 연결 후 Redeploy)가 안 된 거예요.

## 다음에 해볼 만한 것
- **라인 랜덤 배정**: 팀 섞을 때 탑·정글·미드·원딜·서폿까지 정해 주기. 기록에 같이 남기면 라인별 승률도 볼 수 있어요.
- **시즌 나누기**: 기간 필터보다 한 단계 더. "시즌 2 시작"을 누르면 MMR을 새로 시작하기.
- **백업 불러오기**: 지금은 받기만 돼요. 받은 JSON을 다시 올려서 복구하는 기능.
- **디스코드 알림**: 경기가 기록되면 디스코드 채널에 결과 보내기(웹훅).
- **챔피언 기록**: 하나씩 적는 건 번거로워서 뺐어요. 후보는 게임 결과 화면 캡처를 붙여넣으면 AI(Claude API)가 닉네임·챔피언·승패를 읽어서 채우고, 확인 후 저장하는 방식이에요. 친구마다 롤 닉네임을 한 번 등록해 두면 누가 무슨 챔피언을 했는지 이어 붙일 수 있어요.
