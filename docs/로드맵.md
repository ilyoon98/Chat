# 똥겜사랑단 놀이터 — 로드맵

> 앞으로의 계획이에요. 지금까지 만든 것은 [기획서](기획서.md)에 있어요.
> 작성: 2026-10-23 (v1.21.0 기준) · 2단계 대부분 v1.21.2에서 했어요

## 방향

기능은 이미 충분히 많아요(이틀 동안 v1.0 → v1.21). 그래서 앞으로는 **새로 더하기보다 실제로 써 보고 다듬는 쪽**이 먼저예요.

1. **쓰는 것 위주로**: 친구들이 실제로 누르는 기능은 더 편하게, 아무도 안 쓰는 기능은 숨기거나 빼서 화면을 단순하게.
2. **기록은 안전하게**: 기록이 날아가거나 잘못 바뀌는 일이 없게.
3. **새 기능은 꼭 필요할 때만**: "게임하면서 옆에서 쓰는 것"처럼 실제 쓰임이 분명한 것만.

## 1단계 — 써 보고 다듬기 (지금 ~ 2주)

| 할 일 | 왜 | 끝났다고 보는 기준 |
|---|---|---|
| **실제 내전에서 한 바퀴 돌려 보기**: 참가 신청 → 팀 섞기 → 승부 예측 → 결과 → MVP·벌칙 → 결산 이미지 | 지금까지 쓰기 동작은 시험용 서버에서만 확인했어요 | 실제 사이트에서 한 저녁(5판 이상) 문제없이 진행 |
| **안 쓰는 기능 정리** | 2026-10-23 기준 MVP 투표 0표, 1:1 0판, 토너먼트 0개 | 2주 써 본 뒤 한 번도 안 쓴 기능은 접어 두거나(설정에서 켜기) 빼기 |
| **폰 화면 다듬기** | 친구들은 대부분 폰으로 봐요 | 폰에서 내전 한 판을 스크롤·오타 없이 진행 |
| **친구 의견 모으기** | 만든 사람만 쓰기 편한 기능이 되지 않게 | 불편한 점 목록을 받아서 고칠 것 / 안 고칠 것 정하기 |

## 2단계 — 안정화 (2주 ~ 1달)

코드 점검(2026-10-22·23)에서 나왔지만 친구끼리 쓰기엔 급하지 않아서 미뤄 둔 것들이에요.

| 할 일 | 내용 | 상태 |
|---|---|---|
| **MVP·예측 표 위조 막기** | 닉네임을 정한 기기만 받아요. 예측 이름은 화면이 보낸 게 아니라 서버에 정해 둔 그 기기 닉네임으로 남겨요. "같은 방을 보고 있던 기기만"은 Ably를 쓰면 구경하는 화면이 서버에 신호를 안 보내서 서버가 알 수 없어 뺐어요 | ✅ v1.21.2 |
| **MVP 표 정리** | 하루 지난 판의 표를 판 기록 안 `mvp`(표 수)로 합치고 표 해시에서 지워요. 판을 기록할 때와 매일 새벽 Cron에서 해요 | ✅ v1.21.2 |
| **예측·참가 신청도 그 방만 갱신** | 둘 다 그 방 버전(`bver`)만 올려요 | ✅ v1.21.2 |
| **지운 기록이 백업으로 되살아나는 문제** | 지운 판·1:1·토너먼트 id를 `lol:gone`에 남기고, 불러올 때 빼요. 전체 초기화는 남기지 않아서 초기화 전 백업으로 다 되살릴 수 있어요 | ✅ v1.21.2 |
| **시험을 저장소에 넣기** | 예전 시험 37개는 다른 컴퓨터 임시 폴더에 있어서 새로 썼어요. `tests/`에 30개, `npm test` 한 번으로 돌려요. 가짜 Redis는 `dev-redis.mjs`(내 컴퓨터 서버와 같이 써요) | ✅ v1.21.2 |
| **코드 나누기 검토** | 제안: **지금은 나누지 않기.** 빌드 없이 파일 하나라 고치고 올리기가 쉽고, 친구용 규모에선 나눠서 얻는 게 적어요. `index.html`이 4,000줄을 넘거나 여러 사람이 같이 고치기 시작하면 ① CSS를 `style.css`로 ② 게임 탭별 `<script type="module">` 순서로 나눠요 | 제안만 |
| **코드 정리** | 연승 세기는 `runOf` 하나로 합쳤어요. 비슷한 표 그리기 합치기는 표마다 칸이 달라서 이득이 적어 보류 | 일부 |

## 3단계 — 기능 후보 (필요해지면)

정해진 순서는 없어요. 1단계에서 "이거 있으면 좋겠다"가 나온 것부터 해요.

| 후보 | 내용 | 필요한 것 |
|---|---|---|
| **디스코드 명령어** | 디스코드에서 `/전적 철수`, `/오늘`, `/예측`을 치면 사이트 기록으로 답해 줘요. 지금은 사이트 → 디스코드 알림만 돼요 | 디스코드 앱(봇) 등록, 서버에 명령 받는 주소 하나 |
| **챔피언 기록** | 게임 결과 화면 캡처를 붙여 넣으면 AI가 누가 무슨 챔피언을 했는지 읽어서 채우고, 확인 후 저장 | Claude API 키(서버 환경변수), 친구마다 롤 닉네임 등록 |
| **라인별 전적·라인 밸런스** | 내전에서 라인마다 승률을 보고, 실력 밸런스 섞기에 라인 실력도 반영 | 라인 배정 기록이 더 쌓여야 해요 |
| **업적·칭호** | "10연승", "벌칙 10번", "토너먼트 우승" 같은 배지를 선수 카드에 | — |
| **디스코드 자동 알림 더하기** | 매달 1일 지난달 MVP·연승왕·벌칙왕 리포트, 방이 만들어지면 "내전 모집 중" | Vercel Cron 하나 더 |
| **롤 말고 다른 게임 순위전** | 마리오카트·테트리스처럼 1등~꼴등이 나오는 게임을 순위로 기록하고 점수 매기기(토너먼트는 이미 아무 게임이나 돼요) | — |

## 하지 않기로 한 것

이야기해 보고 지금은 안 하기로 한 것들이에요. 다시 필요해지면 그때 꺼내요.

| 아이디어 | 이유 |
|---|---|
| 챔피언 랜덤 배정 | 롤 안에 이미 랜덤(무작위 총력전 등)이 있어요 |
