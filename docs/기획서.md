## 3. 사용자와 권한

로그인은 없어요. 기기마다 화면이 만든 id(`x-device`)와 닉네임으로 사람을 구분해요.

| 누구 | 할 수 있는 것 |
|---|---|
| **구경하는 사람**(닉네임 없이도 됨) | 모든 기록 보기, 결과 이미지 만들기, 카톡용 복사 |
| **닉네임을 정한 사람** | 위 + MVP 투표, 승부 예측, 참가 신청, 인게임 타이머, **선수 명단 고치기**(추가·이름 바꾸기·빼기·Riot ID), 새 방 만들기, **1:1 기록·토너먼트 만들기** |
| **만든(기록한) 사람** | 자기가 기록한 1:1 지우기, 자기가 만든 토너먼트의 결과 누르기·지우기 |
| **그 방 방장** | 그 방의 오늘 할 사람·팀 섞기·라인·승패 기록·되돌리기·벌칙 룰렛 |
| **어느 방이든 방장** | 내전 기록 삭제(한 판·여러 판), 전체 초기화, 백업 불러오기, 새 시즌, 모든 1:1·토너먼트 지우기·결과 |

- **방장**: 새 방을 만든 사람. 구경하는 사람에게 넘길 수 있고, 10분 동안 신호가 없으면 자리가 비어서 누구나 "방장 하기"를 할 수 있어요.
- **비밀번호(`RECORD_PIN`, 선택)**: 넣으면 기록을 바꾸는 동작에 비밀번호가 필요해요. MVP 투표·승부 예측·인게임 타이머·닉네임 정하기·롤 정보 새로고침은 비밀번호 없이 돼요.

## 4. 화면 구성

```
[머리] 똥겜사랑단 놀이터 · 버전/패치노트 · 🔊 소리 · 연결 상태
[방 줄]   🏠 방 이름 · 👑 방장 · 구경 n명  ▾ (누르면 방 바꾸기·만들기·넘기기·닫기)
[게임 탭] 롤 내전 | 롤 1:1 | 롤 5인 큐 | 토너먼트 | 인게임 타이머 | 선수 명단
   └ 롤 내전 안: 내전 | 전적 | 분석 | 기록
```

- 방은 모든 게임 탭이 같이 써요. 방에 들어가 있으면 한 줄로 접혀 있고, 방이 없거나 닉네임이 없으면 펼쳐져 있어요.
- 폰에서는 게임 탭이 한 줄로 나오고 옆으로 밀어서 골라요.
- 처음 들어오면 닉네임을 묻고, "닉네임 없이 구경만 할게요"로 넘어갈 수 있어요(그 기기에 기억).
- 선수 이름에 마우스를 올리면(폰은 누르면) **선수 카드**가 떠요: 내전 승패·MMR 그래프·이 방 승패·1:1·MVP·토너먼트 우승·내전 라인·솔랭·주 라인·모스트·숙련도.

## 5. 기능 상세

### 5-1. 롤 내전 › 내전 (진행)
1. **방**(맨 위 방 줄): 새 방을 만들거나 열린 방에 들어가요. 방마다 오늘 할 사람·팀 배치·타이머가 따로라서 두 판을 동시에 해도 안 섞여요. "방 링크 복사"로 카톡에 보내면 바로 그 방으로 와요. 12시간 조용한 방은 정리돼요(최대 10개).
2. **오늘 할 사람 고르기**: 방장이 명단에서 이름을 눌러 내리거나, 친구가 **🙋 참가 신청**(내 이름을 한 번 고르면 다음부터 "참가하기"·"빠지기" 버튼 하나)으로 스스로 들어와요.
3. **팀 섞기** — 세 가지 방식
   - **완전 랜덤**
   - **실력 밸런스**: 두 팀 MMR 평균이 가장 비슷한 조합 몇 개 중에서 무작위.
   - **팀장 뽑기**: 팀장 정하는 방법(MMR 1·2위 / 꼴찌 둘 / 랜덤) → 동전으로 먼저 뽑을 팀 → 차례인 팀장이 원하는 만큼 뽑고 넘기기. 팀장 이름이 차르르륵 돌다가 멈추는 효과.
   - **11명 이상**이면 10명만 뛰고 나머지는 "💤 이번 판 쉬어요"(규칙은 6장).
   - 다시 섞으면 바로 전 판과 똑같은 나눔은 피해요.
4. **라인 배정**(끄고 켜기): 팀마다 탑~서폿을 롤 기록·내전 라인으로 추천. 방장은 라인 칸을 눌러 바꿔요.
5. **팀 고치기**: 이름 옆 화살표로 상대 팀으로, 끌어서 자리 바꾸기(폰은 꾹 눌렀다 끌기), "⇄ 블루·레드 바꾸기", 카톡용 복사(라인 순서, 쉬는 사람 포함).
6. **팀 아래**: 두 팀 MMR과 예상 승률 막대, **🔮 승부 예측** 버튼(누구나 한 번).
7. **결과 기록**: "1팀 블루 승리 / 2팀 레드 승리"를 누르면 기록, 승리 효과와 색종이. 기록 뒤에는:
   - 선수마다 MMR 전→후(+n), 3연승·3연패 이상 알림(🔥/🧊)
   - **⭐ MVP 투표**(누구나 한 표, 24시간), **🎡 진 팀 벌칙 룰렛**(방장, 구경 화면도 같이 돎, 결과는 그 판 기록에 남음)
   - 예측을 맞힌 사람, **결과 이미지**(PNG, 폰은 공유 창 / 컴퓨터는 복사)
   - **↶ 되돌리기**, **새로 섞기**, **같은 팀으로 한 판 더**
8. **이 방 기록**: 이 방에서 한 판만 센 순위·승패·흐름·MVP·벌칙 목록. **카톡용 복사**와 **결산 이미지**(순위·⭐·승률 막대·벌칙을 그림 한 장).

### 5-2. 롤 내전 › 전적
선수별 내전 티어·솔랭·주 라인·모스트·숙련도·판·승-패·승률·MMR·MVP·최근 5판·연승/연패. 머리글을 눌러 정렬. **시즌**(지금 / 지난 / 전체)과 **기간**(전체 / 30일 / 7일 / 24시간)으로 걸러 봐요.

### 5-3. 롤 내전 › 분석
- **한눈에 보기**: 승률 1위, 최강·최악 듀오, 가장 일방적인 상대, MVP 최다(최소 판수 1·2·3·5 고르기).
- **명예의 전당**: 최장 연승, 최고 MMR, 하루 최다승, 최다 출전, 최다 출전 듀오, 벌칙왕, 최장 연패.
- **🔮 예측왕**: 결과가 나온 승부 예측의 적중 수·적중률 순위.
- **선수 상세**: 고른 선수의 📈 MMR 그래프(시즌 시작 1000부터 판마다), 천적·먹잇감·찰떡 듀오·안 맞는 듀오.
- **상대 전적표**: 가로줄 선수가 세로줄 선수를 상대로 몇 승 몇 패(색으로 잘 이김/잘 짐).

### 5-4. 롤 내전 › 기록
- 날짜별 경기 카드(시각·방·두 팀·승패·MVP ⭐·벌칙), 판마다 결과 이미지·삭제(두 번 눌러 확인).
- 24시간 안 판은 MVP 투표가 한 줄로 접혀 있고, 누르면 펼쳐져요.
- 시즌이 바뀐 자리에 "🏁 시즌 N 시작" 줄.
- **☑ 여러 판 고르기**(방장): 판마다 체크·이날 전체·전체 → 고른 n판 삭제(두 번 눌러 확인).
- **🏁 새 시즌 시작**(방장, 3초 안에 두 번).
- **백업 받기**(누구나) / **백업 불러오기**(방장): 지금 없는 것만 더해요.
- **전체 기록 초기화**(방장): ① 백업 받기 → ② "초기화" 적기 → ③ 초기화. 선수 명단·Riot ID·방은 남아요.

### 5-5. 롤 1:1
두 명을 고르고(⇄로 자리 바꾸기) 규칙(자유·퍼블·100CS·첫 타워)을 정해 이긴 사람을 눌러요(닉네임을 정한 사람 누구나, 지우기는 기록한 사람·방장). 1:1 MMR 순위(내전과 따로), 최근 1:1, 결과 이미지, 맞대결 전적.

### 5-6. 롤 5인 큐
같이 솔랭·일반을 돌릴 다섯 명을 고르면, 각자 최근 판(사람당 최대 100판)의 라인별 판수·승률·챔피언으로 5명을 5개 라인에 놓는 120가지를 모두 계산해서 1~3순위 배치와 💀 최악의 배치(점수가 가장 낮은 배치, 기록이 있어서 1순위와 차이가 날 때만)를 보여 줘요. 고른 5명은 그 기기에만 기억해요.

### 5-7. 토너먼트
게임 이름(아무 게임이나)과 참가 방식(개인전 / 2·3·5인 팀)을 고르고 참가할 사람을 누르면 2~32 대진표를 짜요. 팀은 무작위로 묶고 순서도 섞어요. 이긴 쪽을 누르면 다음 라운드로, 같은 줄을 다시 누르면 풀려요. 결승이 끝나면 🏆 우승·디스코드 알림·선수 카드 우승 횟수(만들기는 닉네임을 정한 사람 누구나, 결과·지우기는 만든 사람과 방장, 최대 50개).

### 5-8. 인게임 타이머
게임하는 동안 옆에 켜 두는 보드예요. 방마다 **블루팀·레드팀·솔랭/일반** 보드가 있고, 같은 보드를 연 친구들과 같이 봐요(누구나).
- 라인마다 상대 스펠 두 칸: 누르면 쿨타임이 돌고, 다시 누르면 취소. 칸 아래에서 스펠을 바꿔요. 👟 신발·🔭 우주적 통찰력.
- 오브젝트(드래곤·바론·장로·억제기) 칸은 v1.22.1에서 뺐어요. 게임 안에서도 시간이 보여서, 게임이 안 알려 주는 상대 스펠만 남겼어요.
- 돌아오면 소리·알림. 게임 시작 버튼(늦었으면 "12:30"처럼 맞추기), **채팅용 복사**("탑 플 23:45 / 원딜 힐 21:10"), 새 게임(두 번).
- 참가 신청한 내 이름이 지금 팀에 있으면 내 팀 보드가 먼저 열려요. 직접 고른 보드는 그 판 동안만 써요.

### 5-9. 선수 명단
한 줄에 한 명씩 세로 목록(티어·이름·라인·솔랭 / Riot ID / 이번 시즌 승패·MMR). 줄을 누르면 바로 아래에서 이름 바꾸기·Riot ID 연결·빼기. **☑ 여러 명 고르기**로 한 번에 빼기. 롤 정보 새로고침(10분에 한 번). 누구나 고쳐요.

### 5-10. 공통
- **패치노트**: 머리의 버전을 누르면 버전마다 바뀐 점이 나와요(새 버전이면 점 표시).
- **효과음**: 팀 섞기·승리·되돌리기·룰렛·동전 등에 짧은 소리(Web Audio로 그때그때 만듦). 🔊로 끄기.
- **디스코드 알림**(설정했을 때): 내전·1:1 결과, 벌칙 당첨, 새 시즌, 토너먼트 우승.

## 6. 핵심 규칙과 계산

| 항목 | 규칙 |
|---|---|
| **내전 MMR** | 1000점에서 시작하는 Elo. 팀 평균 MMR로 예상 승률 `1 / (1 + 10^((상대 평균 − 우리 평균)/400))`을 구하고, K=24로 이긴 팀은 +, 진 팀은 − 같은 만큼. 판 순서대로 다시 계산해요 |
| **1:1 MMR** | 내전과 따로, 1000점 시작 Elo, K=32 |
| **내전 티어** | 지금 시즌 MMR 순위가 우리 중 상위 몇 %인지를 실제 솔로랭크 분포(챌린저 0.0092% … 아이언)에 맞춘 엠블럼. 그 시즌에 1판 이상 한 사람만 |
| **실력 밸런스** | 가능한 나눔을 모두(14명 이하) 또는 4,000개 표본으로 계산해서 평균 MMR 차이가 가장 작은 쪽 +8점 안의 조합 최대 12개 중 무작위 |
| **11명 이상 쉬기** | 10명만 뛰어요. 오늘(12시간 안) 이 방 판을 보고 ① 지난 판에 쉰 사람(새로 온 사람 포함) ② 덜 뛴 사람 순, 같으면 무작위 |
| **같은 나눔 피하기** | 두 팀을 정렬한 열쇠가 바로 전 판과 같으면 다른 조합을 골라요(다른 조합이 있을 때) |
| **판(round)** | 팀을 섞거나 옮기거나 진영을 바꾸거나 "한 판 더"를 누를 때마다 새 판. 같은 판은 두 사람이 동시에 눌러도 기록 하나만 남아요 |
| **MVP** | 닉네임을 정한 기기마다 한 판에 한 표, 기록하고 24시간 안. 가장 많이 받은 사람(같으면 같이)이 MVP. 누가 누구를 뽑았는지는 안 보여요. 24시간이 지나면 표를 판 기록 안 `mvp`(표 수)로 합쳐요 |
| **승부 예측** | 닉네임을 정한 기기마다 한 판에 한 표(이름은 서버에 정해 둔 그 기기 닉네임), 지금 그 방 팀 배치의 판에만, 결과 기록 전까지. 진영을 바꾸면 새 판이라 다시 찍어요. 판을 지우거나 되돌리면 그 판 예측도 지워져요. 결과 없이 버려진 판의 예측은 사흘 뒤 지워요 |
| **벌칙 룰렛** | 진 팀 한 명(2명 이상이면 "진 팀 전체"도 후보)과 벌칙 하나. 결과는 방 팀 배치와 그 판 기록에 저장 |
| **시즌** | 시즌 시작 시각만 저장하고 판 시각으로 나눠요. 새 시즌은 내전·1:1 MMR이 모두 1000점부터. 지금 시즌에 판이 없으면 시작 못 해요 |
| **스펠 쿨타임** | 기본 × 100 / (100 + 스펠 가속). 신발 10, 우주적 통찰력 18. 점멸 300·순간이동 360·점화 180·탈진/정화/회복/유체화 240·방어막 180·강타 90초 |
| **토너먼트 대진** | 참가자 n명이면 2의 거듭제곱 P로 올리고, 1라운드는 위쪽 절반이 각 판의 a, 나머지가 앞 판부터 b(빈자리는 부전승). 이긴 쪽은 다음 라운드 '판 번호/2' 판으로 |
| **이름 합치기** | 이미 있는 이름으로 바꾸면 전적이 합쳐져요. 같은 판·같은 1:1·같은 토너먼트·지금 팀에 둘 다 있으면 다른 사람이라 막아요 |
| **제한** | 선수 60명, 내전·1:1 각 5,000판, 방 10개, 토너먼트 50개, 닉네임은 30일 안 쓰면 풀려요 |

## 7. 데이터 저장 구조 (Upstash Redis)

| 키 | 내용 |
|---|---|
| `lol:players` | 선수 이름 목록 |
| `lol:matches` | 내전 판(해시): `{ t, blue[], red[], win, room, round, lanes?, penalty?, mvp? }` (`mvp`: 투표가 끝난 뒤 합친 `{ 이름: 표 수 }`) |
| `lol:duels` | 1:1 판(해시): `{ t, a, b, w, rule, by? }` (`by`: 기록한 기기의 짧은 열쇠) |
| `lol:mvp` | 투표 중인 MVP 표(해시): `판id|기기id` → `{ n, t }`. 24시간 지나면 판 기록으로 옮기고 지워요(`lol:mvp:lock`: 동시에 옮기지 않게 1분 잠금) |
| `lol:gone` | 일부러 지운 판·1:1·토너먼트 id → 지운 시각. 백업 불러오기에서 빼요 |
| `lol:pred` | 승부 예측(해시): `판round|기기id` → `{ s, n, t }` (화면에는 기기id 대신 짧은 열쇠만) |
| `lol:tourn` | 토너먼트(해시): `{ name, game, ents, rounds, champ, t, doneAt, by?, byNick? }` (`by`: 만든 기기의 짧은 열쇠) |
| `lol:seasons` | 시즌 시작 시각 목록 |
| `lol:riot`, `lol:riot:games`, `lol:riot:lock`, `lol:riot:rest` | Riot ID·롤 정보, 모아 둔 판, 동시 호출 막기, 호출 쉬는 시각 |
| `lol:rooms`, `lol:hostseen`, `lol:nicks` | 방 정보, 방장 마지막 신호, 기기별 닉네임 |
| `lol:ver` | 전체 버전(기록이 바뀔 때마다 1씩) |
| `lol:room:<방>:sel` | 그 방 오늘 할 사람(정렬 집합) |
| `lol:room:<방>:cur` | 그 방 팀 배치 `{ blue, red, t, round, lanes?, bench?, penalty? }` |
| `lol:room:<방>:seen` | 지금 보고 있는 사람(정렬 집합, 점수 = 마지막 신호) |
| `lol:room:<방>:board:<blue·red·solo>` | 인게임 타이머: `start`, `r:라인`, `e:라인:칸` |
| `lol:room:<방>:bver` | 그 방 타이머 버전 |

## 8. 외부 연동과 설정

| 이름 | 쓰는 곳 | 없으면 |
|---|---|---|
| `UPSTASH_REDIS_REST_URL/TOKEN` (또는 `KV_REST_API_*`) | 모든 기록 저장 | "DB 연결 필요" |
| `RIOT_API_KEY` | 솔랭 티어·주 라인·모스트·숙련도·5인 큐(KR 서버, 2분에 100번 제한을 나눠 써요) | 롤 정보 칸이 안 보여요 |
| `ABLY_API_KEY` | 실시간 '바뀜' 신호·보고 있는 사람 | 5초마다 물어봐요 |
| `DISCORD_WEBHOOK_URL` | 결과·벌칙·시즌·우승 알림(4초 안에 답 없으면 포기, 멘션 막음) | 알림 없음 |
| `RECORD_PIN` | 기록을 바꾸는 동작에 비밀번호 | 누구나 기록 |
| `CRON_SECRET` | 매일 새벽 4시 롤 정보 모으기(`vercel.json` crons)를 Vercel만 부르게 | 누구나 부를 수 있음 |

- 서버 함수는 **서울(icn1)** 에서 돌아요(`vercel.json` regions).
- 챔피언 이름·아이콘은 라이엇 Data Dragon에서 받아요.

## 9. 실시간 갱신과 속도

- 기록이 바뀌면 `lol:ver`가 오르고, Ably가 있으면 '바뀜' 신호를 쏴요. 화면은 신호가 올 때와 2분마다(놓친 게 있을까 봐)만 물어봐요.
- Ably가 없으면 5초마다 물어보고, 5분 넘게 안 만지면 30초, 30분 넘으면 5분 간격.
- 물어볼 때 버전이 같으면 서버는 DB를 1번만 보고 "같아요"만 답해요.
- 인게임 타이머·승부 예측·참가 신청은 전체 버전 대신 **그 방 버전**(`bver`)만 올려서, 그 방 화면만 다시 받아요.
- 상태를 읽을 때 방 정보까지 한 번에 같이 읽어요.
- 실제 사이트 응답: "같아요" 확인 약 **0.07초**, 전체 기록 약 **0.08초**(서울 이전 전 0.4~0.9초).

## 10. 실수와 장난을 막는 장치

- 지우기·새 시즌·새 게임·여러 명 빼기는 **두 번 눌러야** 돼요(3초 안).
- 전체 초기화는 **① 백업 → ② "초기화" 적기 → ③ 초기화** 순서로만.
- 같은 판 중복 기록 막기(판 번호), 1:1은 15초 안 같은 결과를 한 번만.
- 백업 불러오기는 지금 없는 것만 더하고, 앞날짜 판과 **일부러 지운 판·1:1·토너먼트**는 빼요(전체 초기화는 빼지 않아요).
- MVP 투표·승부 예측은 닉네임을 정한 기기만 받아요.
- 화면에 넣는 이름·글은 모두 HTML 이스케이프, 디스코드는 멘션이 안 불리게.
- 적는 중(이름·Riot ID·벌칙 목록·타이머 시간)에는 화면을 다시 그리지 않아요.

## 11. 운영

- **배포**: GitHub `main`에 올리면 Vercel이 자동으로 배포해요(10~20초).
- **버전 규칙**(`CLAUDE.md`): 올릴 때마다 `주.부.수`를 올리고, `index.html`의 `NOTES`(패치노트), `package.json`, 커밋 메시지 앞, git 태그를 같은 버전으로.
- **백업**: 기록 탭 "백업 받기"로 JSON 파일(명단·내전·1:1·MVP·시즌·토너먼트·Riot ID).
- **서버 시험**: `npm test`(`tests/`, 가짜 Redis `dev-redis.mjs`). 올리기 전에 돌려요.
- **내 컴퓨터에서 시험**: `npm run dev` → http://localhost:3000. 기록은 `.dev-data.json`에 저장되고 실제 사이트와 따로예요. `DEV_DATA`·`PORT`·`DEV_LATENCY`로 파일·포트·지연을 바꿀 수 있어요.
